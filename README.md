# Student Monthly Membership Tracking System

A backend system for managing student memberships, payments, and authentication with Node.js and Express.

## Features

- ✅ Student CRUD operations
- ✅ JWT Authentication
- ✅ Role-based access control
- ✅ In-memory data storage (easy to switch to database)
- ✅ Clean and modular architecture

## Technologies Used

- Node.js
- Express
- JSON Web Tokens (JWT)
- BcryptJS (password hashing)
- Dotenv (environment variables)
